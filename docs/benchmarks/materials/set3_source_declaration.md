# Source declaration — Set 3 (fixed for all arms; Step 1 output)

- **Research question (deductive):** Which emotions does the writer of the comment express? Fixed category set: 27 emotions + neutral (GoEmotions taxonomy).
- **Source type:** naturally occurring user comments — short English Reddit comments, no thread or subreddit context supplied (matching the original annotation condition).
- **Producer:** anonymous Reddit users; **purpose/audience:** informal online conversation.
- **Unit of analysis:** one comment (unit = document).
- **Elicitation:** naturally occurring; `Prompting` = `n/a`.
- **Co-coding rule (fixed for all arms):** assign one or more emotion categories only when reasonably confident that the *writer expresses* that emotion; otherwise `neutral` **alone**. `neutral` is never combined with an emotion. Classify expressed emotion, not an emotion merely mentioned or the emotion a reader might feel. Sarcasm may invert literal sentiment, but only with a cue in the text.
- **Evidence:** the whole comment is the excerpt (attached mechanically by ID); give a 3–8-word reason per unit instead of selecting a passage.
- **Language:** English. **Completeness:** a random sample of the official test split.
- **Coding logic:** deductive; the codebook is fixed for the run.
